# 🎓 Elimu Analytics

Class performance analytics for Kenyan schools.

## What it does
- Upload a CSV of class marks
- View class mean, subject averages, top students, at-risk students
- Track performance across 3 terms and 6 exams

## How to use
1. Upload your marks CSV (format: student_id, name, class, term, exam_type, subject, marks, out_of)
2. Explore the tabs: Overview, Trends, At-Risk, Top Students

## Built with
Streamlit · Pandas · Matplotlib · Seaborn
